# Aurora Project Overview

Aurora is a solar farm monitoring initiative for the Riverina grid-scale site. It ingests inverter readings every five seconds.

## Telemetry Dashboard

The telemetry dashboard is the flagship deliverable: a single screen that replaces three spreadsheets operators currently reconcile by hand each morning.
