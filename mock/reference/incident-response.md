# Incident Response Procedure

## Incident Response Steps

1. Confirm the incident is real, not a monitoring glitch.
2. Page the on-call lead for the affected project.
3. Open a journal entry and link it from this incident response procedure.

## Scope

Covers both Aurora telemetry outages and Beacon field failures.
