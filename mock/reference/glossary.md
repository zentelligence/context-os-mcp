# Glossary

- **Telemetry** — periodic sensor readings sent from a device to a server.
- **Firmware** — software embedded on a microcontroller.
- **Watchdog timer** — hardware timer that resets a stalled device.
- **Ingestion worker** — service that validates and stores incoming readings.
- **Single point of failure** — a component whose failure stops the whole system.
